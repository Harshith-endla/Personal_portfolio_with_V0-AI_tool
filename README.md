# Endla Harshith Varma | Portfolio Website

A modern, responsive personal portfolio website built to showcase my background, skills, education, projects, and contact information. The site is designed with a clean user experience, smooth animations, and a professional presentation suitable for personal branding and career opportunities.

## Overview

This project is a personal portfolio website for Endla Harshith Varma, a Computer Science Engineering student with interest in Web Development and DevOps. It includes sections for:

- About me
- Education
- Skills
- Experience
- Projects
- Contact details
- Resume download

The website is lightweight, fast, and easy to customize for any personal portfolio use.

## Getting Started

### Prerequisites

Before running this project, make sure you have:

- Node.js installed
- npm or pnpm installed

### Installation

1. Clone the repository:

```bash
git clone https://github.com/Harshith-endla/Personal_portfolio_with_V0-AI_tool.git
cd Personal_portfolio_with_V0-AI_tool
```

2. Install dependencies:

```bash
npm install
```

3. Start the local server:

```bash
npm run dev
```

4. Open the browser at:

```text
http://localhost:3000
```
